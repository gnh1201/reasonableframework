# End of life

[한국어](eol.ko.md)

Security updates follow the versions below. The same table is in [SECURITY.md](../SECURITY.md).

| Version | Supported |
| ------- | --------- |
| 1.6.x | :white_check_mark: Current |
| 1.5.x | :x: EOL 2020-08-25, legacy |
| < 1.5 | :x: Legacy |

Products built on Legacy ReasonableFramework (version 1.5 or below) include:

- Web-based real estate brokerage systems
- HR systems for job search and recruitment
- Image thumbnail and file upload systems
- Hotel reservation systems
- BOM (bill of material) systems
- Realtime score dashboards for sports games

Maintenance of this repository is limited to security patches for existing users. The project does not take on refactoring or renewal of systems built on Legacy ReasonableFramework. Questions about a new system, or about an existing one, can go to the contacts below.
