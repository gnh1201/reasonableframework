# ReasonableFramework 문서

[English](README.md)

ReasonableFramework는 RVHM 구조의 PHP 프레임워크입니다. RSF, VSPF, C-2020-018490이라고도 부릅니다. 저장소는 [gnh1201/reasonableframework](https://github.com/gnh1201/reasonableframework)입니다.

이 문서는 catswords-oss.rdbl.io 작업공간 `7839294550`에 올라 있던 페이지를 되돌리고, 예제를 이 저장소에 맞게 다듬은 것입니다.

## 페이지

- [사용 사례](use-cases.ko.md). Grafana로 보내는 자빅스 심각도, 네이버 파파고 API, KCP 결제 라우트.
- [REST 클라이언트 (webpagetool)](rest-client.ko.md)
- [연동](integration.ko.md). 모듈 목록과 정적 파일 호스팅(카페24 CDN, Amazon S3, 오브젝트 스토리지).
- [지원 종료](eol.ko.md)
- [중요 업데이트](important-updates.ko.md). 2019-10-04 데이터베이스 노트.
- [대체 데이터베이스 접속](alternative-database-connector.ko.md)
- [SQLX (SQL Extendable)](sqlx.ko.md)
- [호스팅 호환](provider-compatibility.ko.md)
