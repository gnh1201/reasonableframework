# Important updates

[한국어](important-updates.ko.md)

## 4 October 2019 (1.6-pre191004)

- `system/database`
  - One way to write every `where` condition for create, read, update, and delete. [#57](https://github.com/gnh1201/reasonableframework/issues/57)
  - Grouped and mixed `or` / `and` conditions. [#57](https://github.com/gnh1201/reasonableframework/issues/57)
  - An `ignore` condition on insert, to skip duplicate rows. [#56](https://github.com/gnh1201/reasonableframework/issues/56)
  - The update parameter list matches insert and delete. [#59](https://github.com/gnh1201/reasonableframework/issues/59)
  - Temporary tables from the system layer. [#60](https://github.com/gnh1201/reasonableframework/issues/60)
- `helper/database.mysql.cmd`
  - MySQL and MariaDB command-line driver.
- `helper/colona.v1.format`
  - A line-oriented format that splits records on `\r\n` and fields on `:`.
