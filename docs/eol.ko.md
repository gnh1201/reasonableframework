# 지원 종료

[English](eol.md)

보안 업데이트는 아래 버전을 따릅니다. 같은 표가 [SECURITY.md](../SECURITY.md)에 있습니다.

| 버전 | 지원 |
| ---- | ---- |
| 1.6.x | :white_check_mark: 현재 |
| 1.5.x | :x: 2020-08-25 지원 종료, 레거시 |
| < 1.5 | :x: 레거시 |

레거시 ReasonableFramework(1.5 이하)로 만든 제품에는 다음이 있습니다.

- 웹 부동산 중개 시스템
- 구인, 구직 HR 시스템
- 이미지 썸네일과 파일 업로드 시스템
- 호텔 예약 시스템
- BOM(자재 명세서) 시스템
- 스포츠 경기 실시간 점수판

이 저장소의 유지는 기존 사용자를 위한 보안 패치로 한정됩니다. 레거시 ReasonableFramework로 만든 시스템의 리팩터링이나 갱신 작업은 받지 않습니다. 새 시스템에 대한 질문이나 기존 시스템에 대한 문의는 아래 연락처로 보내면 됩니다.
