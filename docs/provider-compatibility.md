# Provider compatibility

[한국어](provider-compatibility.ko.md)

ReasonableFramework aims to run on the PHP web hosting plans used in Korea. This table is the one published on catswords-oss.rdbl.io. The [README](../README.md) keeps a shorter table and links Vultr through `https://catswords.re.kr/go/vultr`.

| [woobi.co.kr](http://woobi.co.kr) (MyCGI) | Passed | v1.6.2 | |
